📖 Description
This project is an interactive 3D visualization viewer designed only for viewing virtual objects and scenes in a realistic digital environment. Users can rotate, zoom, and navigate within the 3D space to enhance their viewing experience. The application demonstrates smooth interaction and real-time rendering using web technologies.

✨ Features
Interactive 3D object viewing
Zoom and rotation controls
Smooth navigation experience
Real-time rendering in browser
Responsive and user-friendly interface

🛠 Technologies Used
HTML
CSS
JavaScript

▶️ How to Run
Download or clone the repository.
Open the project folder.
Run the index.html file in your browser.
